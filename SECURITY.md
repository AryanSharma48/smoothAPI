# Security Policy

## Supported Versions

Please check the table below for versions of SmoothAPI that are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.x.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for SmoothAPI. We kindly ask that you **do not publicly disclose** any security vulnerabilities you find (e.g., via GitHub Issues). 

Instead, please report them by sending an email to **[security@smoothapi.org]** or by opening a private **GitHub Security Advisory** in this repository.

### What to include in your report:
* A description of the vulnerability.
* The environments or packages affected (e.g., `smooth-api-ts`, `smooth-api-py`).
* Steps to reproduce the issue (a minimal code example is highly appreciated).
* Any potential impact or risk you foresee.

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress. If the vulnerability is confirmed, we will release a patch and publish a security advisory acknowledging your contribution.
